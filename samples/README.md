# Published output samples

These layout JSON files use the TimeLighting format and were generated by the current implementation.
Run the commands below from the repository root. New results are saved to `output/`, which is excluded from Git.
All samples use `seed=0`, NumPy repulsive forces, the default iteration counts, and Graphviz `sfdp`.
Their reproduction commands explicitly include `--graphviz`; without this flag,
the current default initializer is NetworkX `spring_layout`.

| Published file | Input | Settings |
| --- | --- | --- |
| `events/layout.json` | `multidynnos_py/examples/events.json` | Default layout |
| `newcomb/layout.json` | `raw/newcomb` | Default layout, AutoTau |
| `newcomb/layout_ar3.json` | `raw/newcomb` | Height/width ratio of 3, final bounding-box fitting |

```bash
python -m multidynnos_py multidynnos_py/examples/events.json --graphviz --repulsion-backend numpy --seed 0 -o output/events.json
python -m multidynnos_py raw/newcomb --graphviz --repulsion-backend numpy --seed 0 -o output/newcomb.json
python -m multidynnos_py raw/newcomb --graphviz --repulsion-backend numpy --seed 0 --aspect-ratio 3 -o output/newcomb_ar3.json
```

To view a sample, set `JSON_PATH` in `view_snapshots.ipynb` to the desired sample path,
such as `samples/newcomb/layout.json`. Set `N_COLUMNS` to the total snapshot count
and `VISIBLE_COLUMNS` to the number shown at once, then run all cells.
The embedded HTML viewer's top slider navigates the horizontal snapshot strip.
Coordinates may vary with the runtime environment and Graphviz version, and execution-time metadata varies between runs.
